# Capture protocol (LiDAR tier, as implemented)
- Walk the room perimeter slowly, keep walls, floor and (if a ceiling height is needed) the ceiling in view; tilt up to the ceiling for a few seconds.
- Pass through every doorway/opening and look back through it, so openings show see-through depth.
- Avoid long featureless corridors without loop closure (drift correction is not implemented).
- Repeat captures of a room should follow the same path for repeatability tests.
- Photo/video protocols: not implemented.
